# Exact pins, not ranges.
#
# Release 2026.08.07 failed CI because `pip install` resolved starlette 1.4.1
# while the machine the code was written on had 1.0.0. starlette 1.4.x wraps
# routes added by include_router in an _IncludedRouter object, so app.routes no
# longer yields a flat list of APIRoute and 99 of the 212 routes became
# invisible to introspection. Nothing was broken at runtime -- the routes still
# answered -- but nothing had pinned the version either, so the same jump was
# queued up to land on the production host on its next deploy.
#
# Every version below is one this project's 24 tests pass against. Upgrades are
# deliberate now: bump a line, run the tests, commit the bump on its own.

fastapi==0.136.1
# Pinned separately and on purpose: fastapi declares only `starlette>=0.46.0`,
# with no upper bound, so pinning fastapi alone does NOT pin starlette.
